# Vibe Player — Homework #25

Учебный музыкальный плеер по выданному макету.

## Структура

- `index.html` — разметка приложения.
- `css/style.css` — светлая и тёмная темы, адаптивная вёрстка и анимации.
- `js/app.js` — логика плеера.
- `tracks.json` — единственный источник данных для списка треков.
- `public/music/jazz/` — аудио Jazz.
- `public/music/classic/` — аудио Classic.
- `public/music/blues/` — аудио Blues.

## Запуск

Так как список треков загружается через `fetch`, проект нужно запускать через локальный HTTP-сервер, а не открывать `index.html` напрямую через `file://`.

Например, в VS Code можно использовать Live Server: нажмите ПКМ по `index.html` → **Open with Live Server**. Сервер должен открывать именно папку `Player`, где одновременно находятся `index.html`, `tracks.json` и папка `public`.

## Реализовано по заданию

- 3 категории: Jazz, Classic, Blues.
- Списки строятся из `tracks.json`.
- Один объект `new Audio()` используется на весь плеер.
- Переключение категорий не останавливает текущий трек.
- Play/Pause.
- Предыдущий/следующий трек по кругу внутри текущей категории.
- Автопереход после `ended`.
- Прогресс и таймер `м:сс`.
- Перемотка кликом по прогресс-бару.
- Громкость и mute с восстановлением прежней громкости.
- Подсветка текущего трека.
- Светлая и тёмная темы.
- Небольшие UI-анимации без изменения логики задания.
